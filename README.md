# nomudev.com

Portfolio and personal brand site of Noel Muñoz — Fullstack Engineer & Software Architect.

Built with Astro 5 (static output), Tailwind CSS v4 and React islands. Deployed to GitHub Pages on every push to `master`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # static build in ./dist
npm run preview
```

Project conventions, design system and roadmap live in [CLAUDE.md](CLAUDE.md).
